# Bienvenido a AI Team Docs

Este es el sistema de documentacion del equipo de agentes.

## Como funciona

- Los **agentes** escriben archivos `.md` directamente en el filesystem
- Los **humanos** los leen y comentan desde esta interfaz web
- Los comentarios se guardan como JSON y los agentes los pueden leer
